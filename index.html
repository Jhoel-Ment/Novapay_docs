                2026-11-20
                v2.14.0
                New ✅
              

              #2026-11-20
            

            
Hosted Checkout Sessions

            

              Added POST /v2/checkout/sessions endpoint for hosted checkout pages.
            

            

              Supports success_url, cancel_url, and multi-currency line items.
              
            

          


          

            

              

                2026-11-15
                v2.13.2
                Update 🔵
              

              #2026-11-15
            

            
Payment Retrieval Rate Limit Increase

            

              Updated rate limits for GET /v2/payments/{id} from 100/min to 200/min.
            

            

              Reflected automatically in X-RateLimit-Limit response headers.
              
            

          


          

            

              

                2026-11-01
                v2.13.0
                Update 🔵
              

              #2026-11-01
            

            
Granular Account Balance Breakdown

            

              The GET /v2/balance endpoint now returns available_balance and pending_balance fields separately.
            

            

              Both fields return integer minor units alongside ISO-4217 currency codes.
